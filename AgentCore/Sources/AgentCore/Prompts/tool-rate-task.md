{{! The rate_task tool's description, as the model reads it. }}
Rate a subagent's work after you've used its report: how well it did the task you gave it. Base the verdict on what you checked (tests you ran, files you read), not on how confident the report sounds. If the work isn't actually done, or its check fails, the verdict is 0 or 1, however good the rest looks. One call per task.
