# Domain knowledge and tool skills for software development (survey, October 2026)

Scope: KNOWLEDGE (K) and TOOL (T) skills for specific domains, as opposed to general process skills. Taxonomy item numbers refer to ~/git/kurtkode/skilllib/TAXONOMY_v0.md.

Method and reliability note: all pages were read over the web (no clones). "Read" below means I fetched the raw SKILL.md (or repo README) and judged it from its content as summarized by the fetch tool; "listing" means the information comes from a registry or aggregator page (Tessl, skills.sh, vibeindex, skillselion, playbooks, etc.) and was not checked against upstream. Star counts are repo-level, rounded, as shown on GitHub on 2026-10-25. Tessl review scores are LLM-judged scores of how a skill is written (conciseness, actionability, progressive disclosure, description triggers), not of whether its technical advice is correct ([Tessl docs](https://docs.tessl.io/improving-your-skills/evaluating-skills)).

## Q1. Language packs: Python, TypeScript/JavaScript, Go, Rust, Swift, Java/Kotlin, C/C++, shell

### Takeaway
Vendor- or expert-authored language skills exist for Python, C++ (Trail of Bits), Swift/SwiftUI (Paul Hudson, Antoine van der Lee), Kotlin (JetBrains, incubator) and Rust (Trail of Bits review only); the best of them are opinionated, toolchain-specific and built around anti-pattern tables, decision trees and reference files. Go, TypeScript, Java and shell have no authoritative publisher: the field is many community "expert" skills that registry reviewers repeatedly fault as generic restatements of what the model already knows.

### Cited Findings
**Python**
- Trail of Bits `modern-python` (read): frontmatter "Configures Python projects with modern tooling (uv, ruff, ty). Use when creating projects, writing standalone scripts, or migrating from pip/Poetry/mypy/black." About 1,900 words; prescribes uv, ruff, ty, pytest+coverage, prek; security tools shellcheck, detect-secrets, actionlint, zizmor, pip-audit; anti-pattern table mapping Poetry/mypy/requirements.txt/pre-commit etc. to replacements; decision tree (PEP 723 single-file scripts vs minimal uv project vs full package vs migration); concrete commands (`uv init --package`, `uv add --group dev`, `uv sync --all-groups`); nine reference files. Directive: "Never manually activate or manage virtual environments—use `uv run` for all commands". Possible defect flagged by the fetch: pytest snippet uses `[tool.pytest]` rather than `[tool.pytest.ini_options]` — [raw SKILL.md](https://raw.githubusercontent.com/trailofbits/skills/main/plugins/modern-python/skills/modern-python/SKILL.md)
- Trail of Bits repo: 46 plugins, CC-BY-SA-4.0, 7.8k stars — [trailofbits/skills](https://github.com/trailofbits/skills)
- wshobson/agents `python-development` plugin: Python 3.12+, Django/FastAPI; skills include async-python-patterns, python-testing-patterns, python-packaging, python-performance-optimization, uv-package-manager — [docs/plugins.md](https://raw.githubusercontent.com/wshobson/agents/main/docs/plugins.md). The repo as a whole: 94 plugins, 202 agents, 185 skills, 105 commands, MIT, 41.7k stars; skills are installable individually via `gh skill` or `npx skills` — [wshobson/agents](https://github.com/wshobson/agents)
- Microsoft `microsoft/skills`: ~174 skills, of which 39 Python, 28 .NET, 25 TypeScript, 25 Java, 7 Rust Azure-SDK skills (suffixes like `-py`, `-dotnet`); MIT, ~3.1k stars, "Work in Progress"; a Copilot-SDK test harness reports 129 skills with 1,169 test scenarios, plus eval specs run in a GitHub workflow — [microsoft/skills](https://github.com/microsoft/skills). These are SDK-usage skills, not general idiom packs.

**C/C++**
- Trail of Bits `modern-cpp` (read): "Guides C++ code toward modern idioms (C++20/23/26)… Replaces raw pointers with smart pointers, SFINAE with concepts, printf with std::print, error codes with std::expected." Contains when-to-use/when-not, anti-pattern table, decision tree, feature tiers (use-now C++20/23, hardening without a standard bump, C++26 reflection, maturing contracts/std::execution), a "rationalizations to reject" table, 10-item checklist, six reference files (anti-patterns.md with 30+ patterns, cpp20/23/26-features.md, compiler-hardening.md, safe-idioms.md). Names concrete flags: `-D_FORTIFY_SOURCE=3`, `-fstack-protector-strong`, `-fstack-clash-protection`, `-ftrivial-auto-var-init=zero`, `-Wl,-z,relro,-z,now`, `-Wunsafe-buffer-usage`, `_LIBCPP_HARDENING_MODE_FAST`. Some statistics stated without sources — [raw SKILL.md](https://raw.githubusercontent.com/trailofbits/skills/main/plugins/modern-cpp/skills/modern-cpp/SKILL.md)
- Trail of Bits also ships `c-review` ("C/C++ security review, with coverage checked against a source parse") and `rust-review` (unsafe boundaries, memory, concurrency, panics, FFI, async, SARIF output) — [trailofbits/skills](https://github.com/trailofbits/skills)

**Swift / SwiftUI**
- Paul Hudson `swiftui-pro` (read): MIT, v2.0.0; "Comprehensively reviews SwiftUI code for best practices on modern APIs, maintainability, and performance." Fixed output format (findings by file with line numbers, violated rule, before/after fix, prioritized summary), ten ordered review steps, 12 reference files (accessibility, api, design/HIG, hygiene, localization, navigation, performance, performance-plus, resizability, data, swift, views). Directive: "Report only genuine problems – do not nitpick or invent issues." — [raw SKILL.md](https://raw.githubusercontent.com/twostraws/SwiftUI-Agent-Skill/main/swiftui-pro/SKILL.md); background in [Hacking with Swift](https://www.hackingwithswift.com/articles/282/swiftui-agent-skill-claude-codex-ai)

**Rules-file ecosystems**
- github/awesome-copilot: MIT, 40.4k stars; instructions folder shows 100+ files incl. go, csharp, dart-n-flutter, java-junit5-assertions, a11y, containerization-docker-best-practices, github-actions-ci-cd-best-practices, kubernetes-*, terraform-for-azure, bicep — [repo](https://github.com/github/awesome-copilot), [instructions dir](https://github.com/github/awesome-copilot/tree/main/instructions)
- PatrickJS/awesome-cursorrules: CC0-1.0, 41.0k stars, ~210 entries in 13 sections, now `.mdc` format with `description/globs/alwaysApply` frontmatter; Next.js has 20+ variants; 99 open PRs — [repo](https://github.com/PatrickJS/awesome-cursorrules)

### Inferences
- The quality pattern among the strong language skills (modern-python, modern-cpp, swiftui-pro) is: narrow opinionated stance + anti-pattern→replacement table + decision tree + exact commands/flags + reference files loaded on demand. Generic "X expert" skills lack the opinion and so add little beyond model priors.
- Language skills earn their keep mostly where the model's priors are stale (new toolchains like uv/ty, C++23/26, SwiftUI for iOS 26+, Kotlin migration), not for stable idioms.
- Gaps by language: Go, TypeScript, Java, shell have no authoritative skill; Rust has only security review and community rule lists.

### Gaps
- Did not read raw SKILL.md files for Go, Rust, TS, Java, or shell community skills; quality claims rely on Tessl reviews.
- Could not confirm license for JetBrains Kotlin skills or AvdLee's skill.
- No install-count data per language skill except scattered listing numbers.

## Q2. Framework and vendor skills (React/Next.js, Django, Rails, Supabase/Postgres, Cloudflare, Stripe, Expo/React Native, SwiftUI, Terraform)

### Takeaway
Vendor-published skills are now the norm for platforms (Vercel, Supabase, Cloudflare, Stripe, Expo, HashiCorp, Microsoft/Azure, Microsoft Playwright), typically MIT/Apache/MPL, and the better ones use an impact-ranked rule index with one file per rule containing incorrect/correct code. Django and Rails lack vendor skills; coverage there is from Sentry (Django review skills) and community catalogs. Vercel's own evals show framework knowledge in skills often goes unused unless the agent is told to load it.

### Cited Findings
- Vercel `vercel-labs/agent-skills`: MIT, 33.0k stars; 8 skills: vercel-optimize, react-best-practices, web-design-guidelines (100+ rules: accessibility, performance, forms, animation, typography, images, theming, i18n), writing-guidelines (80+ rules), react-native-guidelines (16 rules), react-view-transitions, composition-patterns, vercel-deploy-claimable — [repo](https://github.com/vercel-labs/agent-skills)

Sample rule `async-parallel` shows sequential awaits vs `Promise.all()`, claims 2–10× improvement — [rule file](https://raw.githubusercontent.com/vercel-labs/agent-skills/main/skills/react-best-practices/rules/async-parallel.md)

### Inferences
- Vendor skills are the highest-signal category: they encode post-cutoff APIs and the vendor's own opinions, and vendors maintain them. The rule-per-file, impact-ranked index pattern (Vercel, Supabase) is the most reusable design.
- Given the Vercel eval, kurtkode should pair framework skills with an explicit trigger or a short AGENTS.md index, rather than relying on description matching.
- Django, Rails, Express/FastAPI, Spring have no vendor-maintained skill.

### Gaps
- Did not read raw Expo, Cloudflare, Stripe, or HashiCorp SKILL.md bodies; quality is unjudged beyond structure.
- Stripe's canonical repo path is inconsistent across sources.

## Q3. Ops and quality tooling (CI, Docker, Kubernetes, Terraform, observability, migrations, query tuning, profiling, upgrades, release, docs, accessibility, web performance, Playwright)

### Takeaway
Tool skills with bundled scripts are rare but strong where they exist (OpenAI gh-fix-ci, Anthropic webapp-testing, Trail of Bits supply-chain auditor, Microsoft playwright-cli). Docker, Kubernetes, observability, profiling, migrations and changelog/release are covered mainly by community skills of uneven quality, and Copilot instruction files are the most concrete free source for CI/Docker/Kubernetes.

### Cited Findings
- CI: OpenAI `gh-fix-ci` (Apache-2.0): uses `gh` to find failing PR checks, pull Actions logs, summarize the failure snippet, draft a plan, implement only after approval; bundles `inspect_pr_checks.py` (non-zero exit while failures remain); external providers (Buildkite) out of scope — [Tessl listing](https://tessl.io/registry/skills/github/openai/plugins/gh-fix-ci), [moltchat mirror](https://moltchat-agent-commons.onrender.com/wiki/gh-fix-ci_skill_(openai%2Fskills).md). openai/skills (28.3k stars) is now marked deprecated in favour of openai/plugins — [openai/skills](https://github.com/openai/skills)
- Sentry `iterate-pr`: iterates on a PR until CI passes and review feedback is addressed; `gha-security-review` reviews workflows for exploitation risk — [getsentry/skills](https://github.com/getsentry/skills) (Apache-2.0, ~1.1k stars, 30 skills)
- Copilot `github-actions-ci-cd-best-practices.instructions.md` (read): `applyTo: '.github/workflows/*.yml,...'`, ~6,000 words, working YAML for job outputs, least-privilege permissions, cache keys, matrices, SHA-pinned actions; deployment/incident sections generic. "Always pin to a full-length commit SHA for maximum security and immutability." — [raw file](https://raw.githubusercontent.com/github/awesome-copilot/main/instructions/github-actions-ci-cd-best-practices.instructions.md)

### Inferences
- The "Tool" skills that clearly beat model priors ship a script with a defined exit contract (gh-fix-ci, supply-chain-risk-auditor, webapp-testing). These are the best templates for kurtkode's T items.
- Docker, Kubernetes, observability, profiling, migrations, changelog/release, dependency upgrades: no authoritative skill; good candidates for kurtkode to write, seeded from Copilot instruction files (Actions, Docker, k8s) and Supabase rules (migrations, queries).
